How to Play

🖥 P1 (Kiri)

  • A/D : gerak
  • W : lompat
  • F : hit
  • S : drop-shot tipis
  • G : smash (butuh energy)
  • T : servis

🖥 P2 (Kanan) / Single

  • ←/→ : gerak
  • ↑ / Space : lompat
  • J : hit
  • ↓ : drop-shot
  • K : smash
  • L : servis

📱 Mobile

  • Tombol ◀ ▶ untuk gerak
  • Hit / 🎯 Drop / Smash / Jump / Serve
  • Energy di bawah nama: smash kuat butuh 25+

🏆 Skor

  • Rally point, pertama ke 21, selisih 2, cap 30
  • Best of 3: menang 2 game, ganti sisi tiap game
  • PERFECT! = timing ideal, pukulan 18% lebih keras
  • Drop-shot (S/↓) jatuh tipis dekat net
